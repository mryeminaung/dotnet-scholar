This repo contains my practice code, assignments, and projects as I learn C# and .NET development through the C# Scholar class offered by Realistic Infotech Group.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/mryeminaung/dotnet-scholar.git

# Navigate to the project
cd dotnet-scholar

# Run a specific day's project
dotnet run --project Week-01/Day1
```
